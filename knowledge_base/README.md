# B 领域深度知识库

每个 .md 文件对应一个研究子领域，记录：
1. **公认痛点**（什么问题大家都在做）
2. **社区共识 & 路线之争**（主流观点 vs 反对观点）
3. **常见误区 / 错误直觉**（哪些"看起来合理"的想法其实是错的）
4. **当前最火的子方向**（最近 6 个月爆点）
5. **可行的创新切入点**

---

## 文件列表

- `mllm_fusion.md` - 多模态大模型的模态融合
- `mllm_visual_tokens.md` - 视觉 token 管理（数量、压缩、位置编码）
- `llm_reasoning.md` - LLM 推理与测试时计算
- `llm_hallucination.md` - 幻觉缓解
- `agent_memory.md` - Agent 长期记忆
- `world_model.md` - 世界模型
- `diffusion.md` - 扩散模型

---

## 使用方式

Idea Forge 生成 A+B idea 时：
1. 加载对应 B 方向的 .md 文件作为上下文
2. 让 LLM 在理解真实领域常识的基础上思考
3. 避免产出"看起来合理但和社区共识相悖"的方案

## 维护原则

- 由领域内的人（任一鸣等）手工维护
- AI 不自动修改（避免污染）
- 每个方向保持 <500 行，提炼精华
